# Autonomous Indoor Inspection Drone

> A professional robotics project for autonomous indoor inspection using **ROS 2**, **PX4**, and **Gazebo**.

---

## 📌 Project Overview

This project aims to develop an autonomous quadcopter capable of navigating indoor environments, detecting obstacles, processing camera data, and performing inspection missions.

The project is developed completely in simulation before deployment on real hardware.

---

## 🚀 Technologies

- ROS 2 Lyrical
- PX4 Autopilot
- Gazebo Jetty
